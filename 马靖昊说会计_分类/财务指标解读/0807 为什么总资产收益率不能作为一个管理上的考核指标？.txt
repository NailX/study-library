# 为什么总资产收益率不能作为一个管理上的考核指标？

今天咱们来聊聊一个财务指标的“灵魂拷问”——总资产收益率（ROA）到底能不能作为管理考核指标？很多人觉得ROA是衡量企业盈利能力的“金标准”，但我要说：它绝对不能作为管理上的考核指标！ 为什么？且听我举个栗子，一探究竟。
一个简单的例子：ROA与ROE的“博弈”
假设某企业有净资产100万元，向银行贷款100万元，清偿利息和税后的纯收益是20万元。此时：
• 总资产收益率（ROA）= 20万 / (100万净资产 + 100万负债) = 10%
• 净资产收益率（ROE） = 20万 / 100万净资产 = 20%
现在，企业再向银行贷款200万元，假设新增贷款带来的收益增量超过利息成本，最终纯收益增至30万元。此时：
• 总资产变为100万净资产 + 300万负债 = 400万元
• ROA = 30万 / 400万 = 7.5%（下降了！）
• ROE = 30万 / 100万 = 30%（上升了！）
看到这里，明眼人应该已经发现了问题。按照总资产收益率来考核，企业增加贷款后，指标反而下降了。但实际情况是，企业的盈利能力增强了，净资产收益率显著提高。这就形成了一个悖论：如果以总资产收益率为考核标准，那么没有管理者愿意去增加贷款，即使这样做对企业整体盈利是有利的。为什么ROA不适合考核？核心矛盾在此！ROA的公式是：净利润 / 平均总资产。而ROE的公式是：净利润 / 平均净资产。关键问题在于：• ROA的分子是股东的收益（净利润），但分母却包含了债权人（银行）的“贡献”（总资产 = 净资产 + 负债）。• 这就像用“股东的成果”除以“股东+债权人的资源”，逻辑上自相矛盾！打个比方：你和朋友合伙开餐馆，你出100万，朋友借给你100万。赚了20万后，ROA是10%（20/200），ROE是20%（20/100）。如果再借200万赚30万，ROA降到了7.5%，但ROE却升到30%。这时候，你要考核的是“你和朋友的总投入的效率”（ROA），还是“你自己的钱赚了多少”（ROE）？显然，作为股东，你更关心ROE！因此，我认为，考核企业效益的指标只能是净资产收益率。总资产收益率则应顺其自然，该升就升，该降就降，不必过于在意。毕竟，企业的最终目的是提升股东的权益，而净资产收益率正是反映这一点的关键指标。ROE是考核的“黄金指标”：• ROE高，说明股东投入的资本被高效利用，收益更高。• ROE的公式还能拆解为：ROE = 销售净利率 × 总资产周转率 × 权益乘数（杜邦分析法），这能帮助管理者从盈利能力、运营效率、杠杆水平三个维度优化管理。考核导向正确：当管理者追求ROE最大化时，会主动平衡利润提升、资产周转和合理举债，而非被单一指标束缚手脚。但ROE也有“陷阱”——高杠杆≠真本事！用ROE考核必须警惕“杠杆滥用”，如果ROE是通过“借太多钱”（高负债）实现的，风险就大了！例如，两家ROE都是20%的同行业企业，一家负债率30%，另一家负债率80%，显然前者更稳健。所以，用ROE考核时必须关注：• 负债结构：有息负债（如银行贷款）是否过高？• 现金流：企业能否持续偿还利息？若企业用借来的钱“拆东墙补西墙”，ROE再高也是空中楼阁。• 行业特性：重资产行业天然需要高杠杆，轻资产行业则应低负债高ROE。管理者要“聪明加杠杆”，而非“被ROA绑架”。回到案例：企业通过贷款将ROE从20%提升到30%，ROA却下降，这恰恰是“聪明加杠杆”的体现——只要新增贷款的收益能覆盖利息成本，股东就赚了！但现实中，若ROA是考核指标，管理者可能因ROA下滑而拒绝贷款，导致企业错失增长机会。因此，考核指标必须站在股东立场，ROE才是核心。总结：ROA是“分析工具”，ROE是“考核标尺”。• ROA的作用：分析总资产的盈利能力，但不能作为管理考核。• ROE的作用：衡量股东资本的收益能力，是考核企业效益的核心指标。• 关键提醒：高ROE需结合低负债率，才能确保企业“又快又稳”。总之，总资产收益率虽然有其参考价值，但绝不应作为管理上的考核指标。而净资产收益率虽然是一个更好的考核指标，但在比较时也要注意企业的负债情况，不能只看表面数字，而忽略了背后的风险。财务指标从来不是非黑即白的教条，但考核指标必须直击商业本质。只有真正理解了指标背后的含义，我们才能做出正确的决策，引导企业走向更加光明的未来。全文完，感谢您的阅读，请收藏转发，顺手点个“赞”或“”~~~~~  扫码关注视频号
