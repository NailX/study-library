# FDR 保卫战

来源：03_研究_基金研究
链接：https://mp.weixin.qq.com/s/mjngmOepYuFrJ1X1TlXmSg

这是因子动物园的第 069 篇独立原创研究文章。

1. 简介 关于多重检验（multiple testing）问题想必已不用多说，川总写量化对相关方法有详尽的介绍。其中，false discovery rate（FDR）及其扩展方法最为常用。【067】遗漏因子、缺失数据与多重检验一文介绍的 RFS forthcoming 的文章 Thousands of alpha tests 在研究对冲基金业绩时也用了该方法。但不知道您有没想过一个问题，近年来，（顶级）研究中为什么要对经典 FDR 方法进行各种看起来繁琐复杂的扩展呢？简言之，答案很明显，原本的 FDR 方法并不是那么有效，至少在金融研究中如此。但真正认识到这一点，并量化地说明其误差，则并不容易。这便是今天的主题。说起来，在这些工作背后，是一个涉及 3 篇发表在 JF 的非常精彩的“互怼”故事。但结果总体还挺和谐。提出 FDR 方法的主角男团在相当程度上认可了后来者的批评，并达成了基本的共识：FDR 虽好，但应谨慎使用。
2. FDR 方法 FDR 方法在生物统计等研究中早有应用。而在金融研究中的应用，则要来得晚很多。最经典的相关研究是 Barras, Scaillet, and Wermers (2010)（BSW (2010)）。BSW (2010) 应用 FDR 方法来分析基金业绩，以尽可能规避多重检验问题。具体的方法已有非常多的介绍，此处只做简略的回顾。FDR 的出发点是某些情况下，拒绝 的原假设而认为基金 有显著的 alpha，单纯是因为运气原因。为了排除运气的影响（即 false discovery），就需要从拒绝了原假设的基金中，剔除掉那些真实 alpha 为 0 的基金。特别地，为了方便，假设零 alpha 基金的 alpha 服从正态分布，那么，平均来看，在显著性水平 下，会各有 的基金错误地被认为具有显著的正（负）alpha。BSW (2010) 据此指出关键在于估计零 alpha 基金的真实占比（记作 ）。同时，鉴于那些 alpha 显著的基金，对应的检验 p 值应较小，而相应地，p 值较大的基金，则应为零 alpha 基金。为此，BSW (2010) 指出，可以选择一个较大的阈值 ，并认为那些 p 值大于该阈值的基金都是零 alpha 基金。因此，可以得到 的估计如下：其中， 为基金总数， 为 p 值大于阈值 的基金数量。在此基础上，可以得到（给定显著性水平 下）有显著正（负） alpha 的基金占比的估计如下：其中， （ ）分别为 p 值小于 且 alpha 均值为正（负）的基金的数量。特别地，上述参数 和 都可以通过最小化相应估计的均方误差（MSE）来得到。但 BSW (2010) 也指出，一般性地取一个较大的常数，也可以得到非常相似的结果。即 FDR 方法的估计结果对于参数不敏感。在实证研究中，BSW (2010) 首先基于 Carhart 四因子模型估计了基金的 alpha，然后应用 FDR 方法进行分析。他们的结果显示，绝大部分基金都没有显著的 alpha（占比高达 75.4%），同时，有一部分基金有显著的负 alpha（占比 24.0%），而只有极少数基金有显著的正 alpha（占比仅 0.6%）。
3. FDR 方法的问题 截至今天，BSW (2010) 引用已多达 789 次，足见 FDR 方法的影响力之大。但也有学者对此提出了挑战。Andrikogiannopoulou and Papakonstantinou (2019)（AP (2019)）便是其中最有代表性的工作。AP (2019) 认为，BSW (2010) 的方法大大低估了有显著 alpha（无论正负）的基金的占比。其原因是基金收益数据的低信噪比（low signal-to-noise）特征与 BSW (2010) 的假设不符。特别地，回顾前一小节的讨论，BSW (2010) 的核心问题是估计零 alpha 基金的占比，而其估计的前提假设是 alpha 显著的基金的 p 值都应很小，从而可以依据那些 p 值大于给定阈值的基金来估计零 alpha 基金的真实占比 。但实际上，真实数据并非如此。为此，AP (2019) 基于与 BSW (2010) 相同的基础数据，做了很多模拟分析，来检验 FDR 方法对参数的敏感性。其结果表明，FDR 方法对参数较为敏感，尤其是对那些会影响到真正有显著 alpha 的基金的 p 值的参数。此处仅举一个例子。表 1：不同 alpha 均值 DGP 下 FDR 估计结果. 数据来源：AP (2019).第二行最后一列（DGP D-2， = 3.5）对应 BSW (2010) 的结果。由于此时有显著 alpha 的基金的平均 alpha 绝对值较大，因此，基本可以满足 BSW (2010) 中有显著 alpha 的基金的 p 值接近 0 的假定，从而得到较为满意的结果。但在其他情况下，则很容易过度接受原假设。例如，第二行第一列显示，在同样的数据生产过程（DGP）下，当 alpha 均值较小时，FDR 方法会将大量 alpha 显著的基金误分类为零 alpha 基金。而最后两组结果的误差则更为夸张。在 DGP D-4 中，真实的零 alpha 基金占比仅 6.25%，但当 alpha 均值较小时，有超过 80% 的基金被 FDR 方法分类为零 alpha 基金。结果令人咋舌！AP (2019) 的各种分析都得到了类似的结果，FDR 方法所依赖的关键假设，并不被基金数据所支持，因而直接套用 FDR 方法来分析基金业绩，很可能得到具有误导性的结论。
4. BSW (2019) 的回应 作为金融，尤其是基金研究领域的大佬，BSW 自然不会轻易认怂，何况是自己的代表作之一。为此，他们针对 AP (2019) 指出的问题，写了一篇回复文章，这便是 BSW (2019)。该文同样将发表在顶刊 Journal of Finance。BSW (2019) 首先承认了 AP (2019) 指出的 FDR 方法存在的一些问题。但在此基础上，他们进一步指出，通过恰当考虑两个设定细节，FDR 方法的误差比 AP (2019) 发现的要小很多。首先是残差波动率的设定。BSW (2010) 和 AP (2019) 在分析中都使用残差波动率的截面均值作为相关参数。但 BSW (2019) 指出，残差波动率的分布是高度有偏的，少量基金的超高波动率大幅拉高了平均水平。为了获得更有代表性的结果，BSW (2019) 用中位数取代了均值。其次是关于参数间的关系。AP (2019) 着重考察的是不同 alpha 均值下 FDR 方法的表现。为了考察其边际影响，AP (2019) 假定残差波动率和观测时期数不变。BSW (2019) 指出这样的假定在现实中并不合理，而应允许残差波动率和观测时期数目随 alpha 均值的变化而变化。具体而言，他们指出，如果一支基金有较高的 alpha 均值和较低的残差波动率，从而有较高的信息比率，这支基金会吸引大量投资者，从而压低其未来的 alpha。因此，上述变量是一起变化的。BSW (2019) 指出，考虑上述细节后，FDR 方法将一支有年化 2% alpha 的基金误分类为零 alpha 基金的概率，从 AP (2019) 估计的 65% 锐减至 32%。虽然问题仍然不小，但远不如 AP (2019) 所指出的那么夸张。当然，BSW (2019) 也承认，结合 AP (2019) 和他们的研究，在金融研究中应用 FDR 方法时，应持谨慎态度。特别地，应首先对基础数据生成过程进行仔细的检查，分析其是否符合前提假设，尤其是当样本较小时。
5. 结语 本文简要回顾了 FDR 方法在金融中的应用及对其所带来的的问题的认识。这可以帮助我们更好地理解一个方法的作用、恰当的应用场景，以及该如何正确地加以利用。相关研究工作以及可能的“论战”，既让我们见识到科学研究的不易，也让我们切身感受到研究之美。
