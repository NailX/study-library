# 假设不存在 α 前提下，哪些基金能获取真正 α ?

来源：03_研究_基金研究
链接：https://mp.weixin.qq.com/s/hUEIL7V_Gd6RTCZAWcmt9g

这里Rit原是指股票i在t时刻收益率，也可以是投资组合或基金的t时刻收益率，本文主要分析基金的情况。Rmt是市场收益率，SMBt是（small minus big）小盘股相对大盘股超额收益率，HMLt（high minus low）是高估值股相对低估值股收益率，ai是剥离了上述三个因子收益率后的收益率，也被解读为基金的alpha，通常alpha越大，基金获取超额收益的能力越强。e是模型残差。
随着越来越多beta因子加入模型，基金的收益率被剥离得越来越充分，alpha也越来越小。换句话说：基金的alpha，很多时候可能来自于某些未知的beta因子，并不是其真正的管理能力的体现。极端情况下，当足够多的beta因子加入模型后，基金收益率剥离后的alpha甚至可能是负。

当然，实际中不可能找到所有能解释市场或基金收益率的beta因子，因此理论上基金还是有可能获得正alpha，以体现自身的优秀管理能力。只不过，这个alpha可能是真的alpha、也可能是由于某些beta因子。所以本文要探讨的问题就是：假设纳入模型的beta因子足够丰富，基金不存在alpha的前提下，还有哪些基金能获取真正alpha？

（1） 风险因子未找到；
（2）“运气”好；单纯由于持仓股票的受到偶然因素刺激跳跃导致；
（3）基金经理真实选股或beta选择能力；
    第三类是我们真正想挖掘到的基金

二、理论简介
    如上所述，如果定价因子不能够很好解释基金收益率，那么alpha甚至 残差部分有很多“未知因子”的贡献，可能是基金经理发现的能够带来超额收益的“特异因子”，恰恰是实力的反应。这里要分两种情况来看：
    1、R 方较高情形，即模型解释度较高。当模型中考虑的beta因子较多的时候会出现这种情况，alpha较小且不显著，残差蕴含的信息较少属于随机扰动的情况更多，由于其不可解释并且随机，但又确实是收益率的一部分，我们称之为“运气”；
    2、R 方较低情形，即模型解释度较低。低于70%甚至低于60%，说明残差含有某种“不知名因子”。这种情景下基金收益率较高，不仅是alpha 高导致，也有残差的成分而且不可忽视。
    本文后面将采用FF5因子以及基于Barra的40风格因子两套体系对基金收益进行剥离，纳入因子较丰富模型解释度整体较高（后面会看到，大多数基金在大多数时段的R^2均高于70%甚至80%），更符合第一种情形。因此这里构造统计检验：

H0：alpha 来源于运气
H1：alpha 不是运气
然后通过构造alpha的分布，如果alpha大于95%置信区间，则拒绝原假设，认为该基金在对应区间内的alpha是实力。

下面以FF5因子模型为例，来简单介绍如何通过bootstrap来构造alpha或Talpha（即alpha的T值，实际操作中我用的是Talpha）的分布完成统计检验，至于Barra40因子（10个风格、29个行业、1个市场）操作过程完全一样。采用bootstrap后构造的基金alpha分布更贴近正态分布，具体原理可参考《Can Mutual Fund “Stars” Really Pick Stocks New Evidence from a Bootstrap Analysis》。

4、对新生成的,ri_b，再利用Fama French五因子模型进行回归，得到新的alpha_b及Talpha_b。在步骤（3）的假设下，它们的真实值应该为0，得到的alpha_b及Talpha_b不为0是因为残差蕴含“不知名因子”。若得到一个正的alpha_b及Talpha_b，可能是因为bootstrap随机抽取时抽到了许多正残差；若得到一个负的alpha_b及Talpha_b，可能是因为bootstrap随机抽取时抽到了许多负残差；

这里要特别注意的是，每一次bootstrap得到的最大alpha_b或Talpha_b，未必来自同一只基金。也就是说，第一次排序，最右边最大的alpha或Talpha可能来自基金A；第二次排序，最右边最大的alpha_b或Talpha_b可能来自基金B。以此类推，原文解释如下：

这么做的目的，是保证每次选取来的最大alpha_b或Talpha_b是所有基金残差重抽样后得到的真正最大的alpha_b或Talpha_b；第二大的alpha_b或Talpha_b也是真正第二大的，而不是仅仅自己跟自己比。当然实际操作中，我发现这个排名基本比较稳定，也就是基金A如果一次bootstrap后的alpha_b或talpha_b排名某个位置，之后的bootstrap得到的alpha_b或talpha_b也基本是同样排名位置。

7、利用以上1000组中大小排序相同位置的alpha_b或Talpha_b，构成对应位置的分布。至此，我们可以利用一支基金的原始alpha_b或Talpha_b ，以及其对应位置的alpha_b或Talpha_b分布，来探究该基金的alpha或Talpha是因为“运气”还是因为基金经理真实的选股“实力”。
由于本文的假设是H0：alpha 来源于运气，因此如果发现原始原始alpha或Talpha统计量大于绝大部分通过bootstrap产生的alpha_b或Talpha_b分布的某个分位数如95%，那么得出结论：拒绝H0，基金的alpha或Talpha不完全是运气。

四、数据及样本区间
1、样本基金同《挖掘主动管理基金中的工具型选手》；
2、数据区间为201601~201906；
3、采用滚动窗口的形式，每个月底，根据过去60个交易日对样本基金的Talpha进行实力或运气的判断，每个基金一共得到42个实力/运气判定数据；

五、结果展示及一点思考
由于我关心的是那些alpha为正的基金，他们的alpha究竟是实力还是运气，所以这里仅列出alphaIR（alpha平均/alpha标准差，兼顾alpha大小和稳定性）排名靠前的60只基金及其真实实力比例，同时也列出了每只基金的42期平均alpha，理论上我们希望买到那些alphaIR靠前的基金中，真实实力概率较高的基金。首先来看FF5因子模型得到的结果：

下面是barra40因子模型的结果：

对比上面两幅图，可以得到一些有意思的结论：

1、FF5因子模型的解释度普遍低于barra40因子模型的解释度，可见纳入因子越多，模型解释度越高，这是废话；
2、采用FF5因子模型，无论是平均alpha还是alphaIR普遍高于采用barra40因子模型，这个跟前面解释一致，纳入模型的因子越多基金越难获取稳定的alpha；
3、barra40因子模型得到alpha实力概率越高于FF5因子模型，这说明经过更多的风险因子剥离后获取alpha更难，但如果确实能获取稳定alph的话，基金经理拥有真是实力的概率更高；同时也说明传统评价方法中，仅关注基金的alpha大小并不合适；
4、alpha高的基金，未必实力占比高，而某些alpha靠后的基金确有较高实力占比。可能原因是某些alpha大的基金其实承担了模型未捕捉到的风险，而其他基金在残差中包括了这些风险因素，这些基金残差重抽样的时候又恰巧抽到了这些大参差，导致这些基金的alpha_b或Talpha_b很大，每次bootstrap都排到靠前位置，使得原Talpha大的基金不能超越这个分布95%分为；当然也可能基金经理知道这个因子并在选股的时候考虑进去了（比如财务造假因子，某些事件驱动因子，某些政治因素？），不过这个概率可能比较低；

最后想说明一点，该方法只是提供了一个判断alpha或Talpha属于实力还是运气的方法，实际结果可能会跟所采用的因子模型有关。此外也有文献（如《《Luck Versus Skill in the Cross Section of Mutual Fund Returns》》）采用的方法是每次bootstrap后得到的alpha_b或Talpha_b不进行排序，这样每个基金的原始alpha或Talpha就是跟自己的alpha_b或Talpha_b比较，也会得到不同的结论（不过跟海通证券还有浙商证券的朋友讨论后，觉得还是排序后更好，也就是跟全行业所有基金选出来对应排名的分布比较，拒绝H0的难度更大更容易把alpha归为运气）。

from pandas import *
import numpy as np
import statsmodels.api as sm

def cal_alph(y,x):#计算原始alpha、Talpha、调整R^2及bootstrap alpha、Talpha x_intecpt = np.hstack((np.ones((len(y),1)),x))
 model = sm.OLS(y, x_intecpt).fit()
 params_raw = model.params[1:]
 resid_raw = model.resid
 alpha_raw = model.params[0]
 Talpha_raw=model.pvalues[0]
 resid_boot=np.random.choice(model.resid,size=len(model.resid))
 y_boot=x.dot(model.params[1:])+resid_boot
 model_boot = sm.OLS(y_boot, x_intecpt).fit()
 alpha_boot = model_boot.params[0]
 Talpha_boot = model_boot.pvalues[0]
 return alpha_raw,Talpha_raw,alpha_boot,Talpha_boot,model.rsquared_adj

def main_fun(factret,fundret,dateindex):
 indexret=read_csv(factret)#读取因子收益率
 fundret=read_csv(fundret)#读取基金收益率 dateindex=list(read_csv(dateindex)["date"]))#读取每个月底的序列 fundname = fundret.columns[1:]
 date=list(fundret.iloc[:,0])
 interval=60
 bootsize=1000
 
 numoffund=fundret.columns.size #first column is date
 indexret_array=indexret.iloc[:,1:]
 indexret_array=np.array(indexret_array)
 fundret_array=fundret.iloc[:,1:]
 fundret_array = np.array(fundret_array)

 result_alpha=DataFrame(columns=fundname,index=dateindex)#储存alpha
 result_adjR=DataFrame(columns=fundname,index=dateindex)#储存调整后R^2
 result_Talpha=DataFrame(columns=fundname,index=dateindex)#储存Talpha result_Talpha_boot=np.zeros((len(dateindex),bootsize,numoffund-1))#储存bootstrap得到的Talpha finalresult_Talpha_boot=DataFrame(columns=range(numoffund-1),index=dateindex)#储存bootstrap得到的Talpha的95%分为 finalresult_fundscore=DataFrame(columns=fundname,index=dateindex)#储存最后实力得分

 for i in range(len(dateindex)):
 endindex = date.index(dateindex[i])+1
 beginindex=endindex-interval
 indexret_sub=indexret_array[beginindex:endindex, 0:]
 for boot in range(bootsize):
 for j in range(numoffund-1): #include date column
 y=fundret_array[beginindex:endindex,j]
 a,b,c,d,r=cal_alph(y,indexret_sub)
 result_alpha.iloc[i,j] = a
 result_Talpha.iloc[i,j] = b
 result_Talpha_boot[i,boot,j]=d
 result_adjR.iloc[i,j]=r
 result_Talpha_boot[i,boot,:].sort()#from small to big

 for i in range(len(dateindex)):
 index_temp=np.argsort(result_Talpha.iloc[i,])
 for j in range(numoffund - 1):
 finalresult_Talpha_boot.iloc[i,j]=np.percentile(result_Talpha_boot[i,:,j],95)
 for j in range(numoffund - 1):
      if result_Talpha.iloc[i, j] > finalresult_Talpha_boot.iloc[i, index_temp[j]]:
 finalresult_fundscore.iloc[i, j] =1
 else:
 finalresult_fundscore.iloc[i, j] =0
 return finalresult_fundscore
