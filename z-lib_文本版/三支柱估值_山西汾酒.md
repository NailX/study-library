## 一、支柱① 资产价值 AV ≈ 400 亿

| 科目 | 金额 | 调整 |
|---|---|---|
| 货币资金 | 97.2 亿 | 面值 |
| 存货 | 147.8 亿 | 白酒基酒随时间增值，重置价值 ≥ 账面 |
| 固定资产+在建 | 67 亿 | 近年新建，重置≈账面 |
| **有息负债** | **0** | 短借/长借/债券全为 0 |
| 商誉 | 0 | 无并购包袱 |

```
AV ≈ 归母净资产 381 亿 ~ 418 亿（存货上浮 10-25%）
AV/市值 = 28%  →  教科书级"轻资产品牌型"（情形C特征）
```

**含义**：AV 只是极端场景地板，对汾酒这类品牌企业没有定价意义——价值不在资产负债表上，在赚钱能力上。

## 二、支柱② EPV ≈ 1110 亿（核心）

### 正常化盈利（本案例最关键的判断）

```
不能用什么：
✗ 2025年122.5亿 —— 大概率是本轮周期利润顶
✗ 2014年3.6亿 —— 那是周期底+公司自身问题叠加

Greenwald式处理：穿越周期的可持续盈利
├ 悲观（下行延续至2027）:  95 亿
├ 中性（2026年底企稳）:   105 亿  ← 基准
└ 乐观（H2渠道补库存）:   115 亿

依据：2026H1已64.4亿，H2为传统淡季；
      汾酒价位带(青花系列200-800元)受消费降级冲击小于茅台但大于玻汾竞品；
      毛利率仍75% → 盈利质量未恶化，只是量的收缩
```

### EPV 计算

```
EPV = 正常化盈利 / WACC

WACC 取 10%：无有息负债、β≈0.75，但行业处下行段，
              股权成本不应按景气期下调（这是DCF常见错误）

EPV(核心) = 105 / 10% = 1050 亿
+ 富余现金 60 亿（货币97亿 − 经营占用~35亿）
= EPV整体 ≈ 1110 亿（每股 91 元）
```

## 三、支柱③ 增长价值 = 全部分歧所在

### 情形判定：确认情形 C（特许权企业）

```
ROE 33.5% (2025) >> WACC 10%
特许权来源：
├ 需求侧：清香型鼻祖+名酒基因，品牌忠诚度高 ★最持久
├ 供给侧：基酒产能储备(存货148亿)与年份酒壁垒
└ 规模经济：全国化渠道网络，光瓶酒(玻汾)大单品摊薄成本
→ 增长有价值，EPV 不是终点
```

### 但增长价值必须扣 fade

```
白酒行业总量自2016年见顶后持续收缩（量减价升逻辑弱化）
汾酒的长期增长中枢 ≠ 历史10%+
fade 调整：行业总量下移 → 永续 g 上限取 2.5~3%

公允价值 = 105 × (1+g) / (10% − g)

  g=0%  → 1050亿（86元/股）
  g=2%  → 1339亿（110元/股）← ≈现价
  g=3%  → 1545亿（127元/股）
  g=4%  → 1820亿（149元/股）
  g=5%  → 2205亿（181元/股）

★ 现价1410亿 隐含永续增长 g* ≈ 2.4%
```

### 市场隐含结构拆解

```
现价 1410亿 = EPV 1110亿 + 增长价值 300亿（占比21%）
→ 市场只给了"温和复苏"的定价，没有泡沫成分
→ 但也毫无 margin of safety：价格 ≈ 中性公允价值
```

## 四、与壹评级 DDM 的交叉验证 ★

| | 三支柱法 | 壹评级 DDM |
|---|---|---|
| 估值 | 1300-1600 亿（g=2-3%） | **2964 亿** |
| 对现价 | 合理区间内 | 低估 116% |
| 隐含假设 | g≈2.4% 永续 | ? |

**反推壹评级 DDM 的隐含假设**：

```
2964亿 对应什么？
若按2025年分红~73亿、分红率60%：
  2964 = 73×(1+g)/(r−g)
  ├ 若 g=3% → r = 5.5%  ← ★折现率过低
  └ 若 r=9% → g ≈ 6.5%  ← ★永续增速过高

两种口径都偏乐观。且壹评级自身给汾酒 growth 仅 2 星——
"growth 2星" 与 "DDM隐含g 6.5%" 自相矛盾。
```

**分歧根源不在算力，在长期增长信念**：

| 场景 | 公允价值 | 结论 |
|---|---|---|
| 白酒=L型总量下行，汾酒仅靠结构升级 | ~1300亿（g≈1.5-2%） | 现价略贵 |
| 行业出清后汾酒份额提升，恢复中速 | ~1550亿（g≈3%） | 现价便宜10% |
| 2027年后重新进入量价齐升（复刻2016-2020） | 2000亿+（g≥4.5%） | 现价低估40%+ |

**我的判断**（基于三支柱纪律）：
- 壹评级 2964 亿需要"未来10年年化8%+增长"支撑，在 2026 年 -26% 的现实面前，这是**把周期顶当常态外推**——正是 Greenwald 批评的"growth is your enemy when you pay for it at the top"
- 三支柱中性结论：**公允区间 1300-1550 亿，现价 1410 亿 = 合理定价**，无安全边际

## 五、结论与操作框架

### 三档价值汇总

```
AV地板     400亿  ← 清算场景，参考意义弱
EPV基准   1110亿  ← 零增长也值这个钱（每股91元）
公允区间  1300-1550亿 ← 含特许权增长价值（每股107-127元）
壹评级DDM  2964亿  ← 需要强复苏信念支撑
```

### Graham 纪律检验（margin of safety ≤ 2/3 价值）

```
中性口径(g=3%, 价值1545亿):
  买点 ≤ 1030亿 → 股价 ≤ 84元（现价 -27%）
  现价 115.60 元 → 不满足买入纪律

观察区:
  ≤ 91元(EPV)   → 增长价值白送，可考虑建仓
  ≤ 84元        → 符合半价纪律，积极买入
  ≤ 73元(悲观g=2%的2/3) → 极端机会（需行业恐慌配合）
```

### 当前状态判定

```
✓ 不是泡沫：增长溢价占比仅21%，PE 11倍处于历史低位区
✗ 不是机会：价格=中性公允价值，margin of safety = 0
= 典型的"好公司、合理价格"——巴菲特会持有，Graham不会买
```

### 风险清单

| 风险 | 对估值的影响 |
|---|---|
| 2026-2027 利润继续双位数下滑 | EPV下移至950亿 → 现价偏贵30%+ |
| 高端价位带(青花30)需求塌陷 | 增长价值归零 → 只剩EPV 1110亿 |
| 渠道库存二次去化 | 短期利润冲击超预期 |
| 消费税改革落地 | 净利一次性下修3-8% |
| 人口结构长期利空白酒总量 | fade加剧，永续g上限压至1-2% |

### 看多催化（跟踪信号）

| 信号 | 含义 |
|---|---|
| 单季营收同比转正 | 下行段结束，EPV基准上修 |

| 批价企稳（青花20/30） | 渠道利润修复，重新补库存 |

## 六、本案例的方法论复盘

1. **正常化盈利是三支柱的灵魂**：汾酒2025年122亿 vs 2014年3.6亿，差34倍——用任一年做基数都会得出荒谬结论。穿越周期取中枢（105亿）才可靠。
2. **AV 对品牌企业只是形式**：28%的AV占比确认了"情形C"，价值判断全部落在 EPV 和增长假设上。
3. **增长价值 = 全部分歧**：三支柱与壹评级差2倍，不是公式之争，是"g取2.4%还是6.5%"的信念之争——而 fade 纪律（72/半衰期）提示：白酒特许权虽持久，但行业总量下移意味着 g 中枢下移，4%+ 的永续增长需要非常强的证据。
4. **EPV 是最大的 sanity check**：无论 DDM 多花哨，"零增长也值1110亿（91元）"是锚。现价高于锚23%，说明你在为增长付费——付多少合理，取决于你对 fade 的判断。
