精读笔记：《The Little Book of Valuation》(达摩达兰, 第2版)

一句话定位：估值只有两种方法——内在估值（value）与相对估值（price），而贯穿全书的主线是"现金流、增长、风险"三要素在企业生命周期各阶段的不同配比。

全书定位

  • 作者 Aswath Damodaran（NYU 金融学教授），本书是其千页巨著《Investment Valuation》的大众版：11 章 + 结论，约 29 万字，案例全部用 2022-2023 年真实公司（Kraft Heinz、Airbnb、Alphabet、Zomato、Toyota）。
  • 开篇即亮明立场："你买金融资产是为了预期能收到的现金流，用'未来有人出更高价'来辩护股价，等于玩昂贵的抢椅子游戏。"【p.1】
  • 本书回答的核心问题不是"估值模型有哪些"，而是"不同阶段、不同类型的公司，估值的难点和 Value Driver 分别是什么"。

核心框架：估值四问 + 内在价值锚

无论估值哪家公司，先回答四个问题：

1. 现金流：现有资产能产生多少现金？（分红 / FCFE / FCFF，口径必须一致）

2. 增长：现金流会增长多快、增长多久？（增长的质量 = 增量资本回报率 ROC/ROE 是否超过资本成本）

3. 风险：现金流的不确定性多大？（折现率：无风险利率 + ERP + β）

4. 生命周期：公司处于哪个阶段？（年轻成长 → 成长 → 成熟 → 衰退 → 特殊：金融/周期商品）

价值 = Σ 预期现金流_t / (1+风险调整折现率)^t  +  终值/(1+r)^n
                ↑现金流            ↑风险(折现率)          ↑增长(终值)
  • 内在价值锚（intrinsic value）：由现金流与不确定性决定，"好公司=高而稳的现金流"；好估值=不需要任何 garnish（不用给协同、管理层、品牌再加溢价，这些已 baked in）【p.71】。
  • 相对估值锚（pricing）：市场给相似资产什么价，你只回答"相对同类公司是贵是贱"。
  • 两条估值真理：所有估值都有偏（先写下自己的偏见再开始）【p.5】；再好的估值也是错的（精度不是估值的质量标准）【p.7】。
  • 修正市场错误需要时间："给市场 3-5 年纠错，比指望下个季度现实得多。"【p.68】

分块详解

1. DCF 三输入（第 2-3 章，KHC 全案）

时间价值工具箱（第 2 章，一切资产的现金流都可拆解为五种形态）【p.15-25】：

单笔现金流现值   PV = CF_n / (1+r)^n
年金             PV = C × [1 − 1/(1+r)^n] / r
增长年金         PV = C₁ × [1 − (1+g)^n/(1+r)^n] / (r−g)
永续年金         PV = C / r
永续增长         PV = C₁ / (r−g)，约束：g < r 且 g < 经济体名义增长率
  • 折现率三分解：消费偏好（实际回报）+ 通胀 + 不确定性溢价【p.17】。
  • 风险观：Markowitz 组合理论——非系统性风险可通过分散化消除，只有无法分散的风险才该获得补偿（β 的思想源头）【p.25-30】。

现金流口径——四选一，口径一致性是第一纪律【p.35-45】：

FCFE = 净利润 + 折旧摊销 − 资本开支 − Δ非现金营运资本 − (偿还本金−新发债)
FCFF = 税后经营利润 EBIT×(1−t) − (资本开支−折旧) − Δ非现金营运资本
     = EBIT×(1−t) × (1 − 再投资率)
再投资率 = (净资本开支 + Δ营运资本) / 税后经营利润
  • 分红太窄（很多公司不分红）；FCFE 是"潜在分红"，巴菲特的"owner's earnings"可视为不含债务现金流的保守版 FCFE【p.39】。
  • 折现率：股权成本 = 无风险利率 + β × ERP；企业价值用 WACC。2023 年 7 月美股隐含 ERP ≈ 5%（1928-2022 历史 ERP 5.06%，两者当时恰好接近）【p.49-51】。
  • 国家风险：ERP 应以公司业务所在地为准，而非注册地；成熟市场用美国基准，风险国上调【p.51】。
  • 恶性通胀/本币折现率换算：美元折现率直接加通胀差即可——"若美国预期通胀 3%、印度 5%，新兴市场公司的卢比折现率中位数 = 13.19% + 2% = 15.19%"【p.113】。

增长与终值（DCF 最 abused 的地方）【p.55-65】：

永续终值 = 第 n+1 年现金流 / (折现率 − 永续增长率)
稳态再投资率 = 永续增长率 / 稳态资本回报率(ROC或ROE)

终值三约束（纪律红线）：

1. 永续增长率 ≤ 经济体名义增长率，更稳妥的拇指法则是不超过无风险利率；

2. 稳态公司要"像稳态公司"：β 回归 1、负债率回归行业均值；

3. 稳态必须配再投资——终值的关键不是增长率，而是稳态期超额回报（ROC vs WACC）：ROC=WACC 时提高增长率对价值零贡献【p.60】。

从企业价值到每股价值四步调整【p.65-69】：+现金、±交叉持股（少数股东权益要减）、−全部有息债务及表外负债（养老金、诉讼）、−管理层期权价值；股本用当前实际股数（不预留未来增发，稀释已体现在负现金流现值里）。

KHC 案例结论：内在价值 $20.60 vs 市价 $36 → 高估；要 justify 市价需"更高收入增长 × 更高利润率"组合，可用敏感性表反推市场隐含预期【p.69】。

2. 相对估值：倍数选择的纪律（第 4 章）

标准化价格 = 市场价值 / 共同变量。三步：找可比 → 标准化 → 调整差异【p.75-77】。

  • 口径一致性检验（definitional test）：分子分母必须同为股权口径或同为公司口径；全样本口径必须统一（都用 trailing 或都用 forward）。P/S、P/EBITDA 分子是股权价值、分母是经营变量，"会让你把任何高负债公司看成便宜货"——不推荐使用【p.79-81】。
  • 分布检验（descriptive test）：倍数是右偏分布（少数高值拉高均值），跨公司比较用中位数而非均值；对数化后可做回归【p.81-83】。
  • Companion Variable（配对变量）——每个倍数有一个主导基本面变量，错配即机会【p.87】：
倍数配对变量低估信号
PE预期增长低 PE + 高 EPS 增长
P/BVROE低 P/B + 高 ROE
P/S净利率低 P/S + 高净利率
EV/EBITDA再投资率低 EV/EBITDA + 低再投资需求
EV/CapitalROC低 EV/Capital + 高 ROC
EV/Sales税后经营利润率低 EV/Sales + 高经营利润率
  • PEG = PE / 预期增长率；两大隐含假设：风险相同、PE 与增长成比例（增长翻倍 PE 翻倍）——后者不成立时高增公司会显得便宜【p.91】。
  • 可比公司 ≠ 同行业：定义是"现金流、增长、风险相似"，电信公司可以和软件公司比【p.88】。样本够大时用截面回归同时控制多变量。
  • 投行和组合管理里"多数所谓估值其实是定价（pricing）"——快、信息少、但反映当下市场情绪【p.77】。

3. 故事与数字之桥（第 5 章）

  • "一堆数字只是财务模型，一个动人的故事可能只是童话。每个数字背后要有故事解释，每个故事背后要有数字支撑。"【p.103】
  • 流程：构建商业故事（业务本质 / 财务史 / 市场空间 / 竞争 / 宏观）→ 3P 检验（Possible 可能、Plausible 可信、Probable 大概率）→ 转成估值输入 → 保持反馈回路。
  • 故事三态：breaks（商业模式被击穿，价值崩塌）、changes（范围重估，价值跳变）、shifts（参数微调）——用新闻判断属于哪一类，而非纠结 EPS beat 几分钱【p.130】。
  • Zomato 案例：同一公司 12 种故事，每股价值 ₹16.58 ~ ₹150.02；"投年轻公司的回报来自比别人错得少，分歧越大机会越大。"【p.128】

4. 期权视角（第 6、11 章）

  • 年轻公司 = 生存期权：两阶段期望价值
失败调整价值 = 持续经营价值 × (1−失败率) + 清算价值 × 失败率
Airbnb: $29,567×0.9 + $29,567×0.5×0.1 = $28,088M 【p.162】

（参考：美国 2006 年成立的企业仅 45% 活过 5 年，24% 活过 15 年【p.137】）

  • 未开发资源储量 = 实物期权（商品公司）：油价波动率越大，未开发储量越值钱；期权价值在商品价格低、储量勉强可行时最大；DCF 会系统性低估这类公司【p.283-286】。
  • 员工期权：正确做法是用期权定价模型估值后从股权价值中扣除，而非简单按稀释调整股数【p.69】。

5. 生命周期各阶段估值法（第 6-9 章）

阶段特征估值要点核心 Value Drivers
年轻成长 (Ch6)无历史、亏损、股权多重索取自上而下：市场规模×份额→收入→目标利润率；期权/股权索取排序；生存概率收入增长、目标利润率、存活率
成长 (Ch7)价值主要来自增长资产、无形资产密集R&D/品牌广告/培训资本化（会计把它们当费用→账面利润与资本开支同时失真）；增长率必须随规模衰减（80% 增长 5 年后规模已 18 倍，且增长吸引竞争反过来压制增长）【p.171-176】增长的衰减速度、利润率可持续性
成熟 (Ch8)价值来自现有资产、并购驱动增长看经营松弛与财务松弛：换管理层/加杠杆/分拆能释放多少价值；警惕商誉噪声经营/财务松弛、管理层变更概率
衰退 (Ch9)收入负增长、ROC<WACC、债务压顶双情景：持续经营 vs 违约清算；永续增长率可为负；资产剥离价值可能高于持续经营持续经营价值、违约概率与后果

6. 金融公司与周期/商品公司（第 10-11 章）

  • 金融公司：债务是"原材料"，无法界定资本开支和营运资本 → 只能估值股权，用 DDM 或"监管资本再投资版 FCFE"；资本充足率是增长的约束【p.243-258】。三种替代：① 股利折现（唯一可观测现金流）；② FCFE 的银行版——把"再投资"重定义为维持增长所需的监管资本增量；③ 超额回报模型（ROE vs 股权成本）【p.250-255】。
股权价值 = 预期明年股利 / (股权成本 − 永续增长率)
  • 周期/商品公司：利润随宏观剧烈波动，高固定成本放大杠杆效应（经营杠杆）；PE 在周期顶点最低（陷阱）、底部最高。归一化三法：跨周期简单平均（美国周期 5-10 年）、利润率平均×当期收入（增长公司适用，直接平均利润会给成长公司过低值）、行业平均【p.269-275】。
  • Toyota 2009 案例：平均税前经营利润率 7.33% × 收入 22,661 = 归一化 EBIT 1,660.7（十亿日元）→ 每股价值 4,735 日元 vs 市价 3,060【p.272】。
  • 商品公司终值约束：资源有限，永续增长假设要打折；归一化商品价（通胀调整历史均价或供求公允价）。

纪律数值（速查）

  • 永续增长率上限：≤ 经济体名义增长率，实操 ≤ 无风险利率【p.58】
  • 稳态再投资率 = g / ROC（如 g=1%、ROC=10% → 再投资率 10%）【p.60】
  • 2023/7 美股隐含 ERP ≈ 5%；历史 ERP（1928-2022）5.06%【p.50】
  • 美国企业存活率：5 年 45%、15 年 24%（BLS 2006 队列）【p.137】
  • 经济周期长度：5-10 年（归一化窗口）【p.270】
  • 新兴市场卢比折现率 = 美元折现率 + 通胀差（如 +2%）【p.113】
  • β 随稳态回归 1；稳态负债率回归行业均值【p.59】
  • 倍数口径：P/S、P/EBITDA 为不一致口径，慎用【p.79】
  • 比较基准用中位数不用均值（右偏分布）【p.81】

常见估值错误 Top 5（散布全书，归纳）：

1. 给永续增长率超过无风险利率/经济体名义增长率【p.58】

2. 稳态期忘了配再投资率（或 g/ROC 不匹配）【p.60】

3. 用当期周期利润做 DCF 或 PE（周期顶部买"低 PE"陷阱）【p.268】

4. 把不分红等同于无价值，或把账面亏损当无现金流的同义词（年轻公司）【p.137】

5. 估值后 garnish：好估值不需要再加"管理层质量溢价"【p.71】

A股实操清单：一页纸估值漏斗

1. 分层归类（先定生命周期，再选工具）：亏损科技/ biotech → Ch6 年轻公司法（市场空间×份额）；高增消费/制造 → Ch7（资本化研发与租赁）；银行/券商/保险 → Ch10 DDM；钢铁/煤炭/有色/航运 → Ch11 归一化；地产链/传统零售 → Ch9 双情景。

2. 现金流体检：从 EBIT×(1−t) 出发算 FCFF，剔除一次性损益；看再投资率是否 >100%（烧钱扩张）或为负（收缩）。

3. 三输入红线自查：永续 g ≤ 无风险利率（A股可用 10 年国债收益率）；稳态 ROC 是否真能 > WACC；β 用行业回归而非单股。

4. 定价交叉验证：PE 必须配 PEG 看（A股成长风格化定价严重）；PB 必须配 ROE（银行股的核心就是 P/B vs ROE 差）；EV/EBITDA 配再投资率。口径不一致的 P/S 直接弃用。

5. 政策/监管当 story break 处理：教培、互联网反垄断、集采——达摩达兰框架下这类事件属"故事击穿"，估值框架应切换而非调参。

6. 国家风险溢价：业务在新兴市场/汇率管制行业，ERP 在美股基准上加国家风险溢价，折现率按业务所在地而非上市地。

7. 每单写下偏见与反方故事（all valuations are biased），留 3-5 年纠错窗口。

跨库衔接

  • 与格林沃尔德三支柱（EPV）：三支柱的资产价值/EPV 相当于本书"现有资产价值"（即 DCF 中 t=0 已投资产的现金流折现），成长性价值对应"增长资产价值"；本书的"ROC vs WACC 决定增长是否创造价值"正是 EPV 法"只有在 ROC>WACC 时增长才有价值"的严格化表述。
  • 与《Investment Valuation》大部头：本书是其压缩版。要深入：期权定价模型（员工期权、实物期权）、APV 法、资本化 R&D 的具体算法、国家风险溢价数据库 → 读大部头对应章节。
  • 与壹评级 DDM 对照：壹评级的 DDM 是本书 Ch10 金融公司 DDM 的一般化（多阶段增长+显性终值）；A股银行股实践 = 本书"股权价值 = D₁/(r−g)" + 监管资本约束增长率，参数（r、g、分红率）来源不同而已。
  • 进阶路径：本书（框架与纪律）→ Damodaran 大部头（工具箱）→ 三支柱 EPV（护城河定性交叉验证）→ 蒙特卡洛/实物期权（不确定性显式化）。
