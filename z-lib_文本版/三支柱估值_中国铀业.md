# 三支柱估值实操 · 中国铀业（001280.SZ）

**方法**：Greenwald《Value Investing》三支柱法（资产价值 / EPV / 增长价值）
**标的**：中国铀业股份有限公司（001280.SZ，中核集团旗下天然铀专营平台，次新股）
**数据基准日**：2026-10-16（行情）/ 2026-06-30（财报）｜**生成**：2026-10-16
**一句话**：再生产价值 ~210亿、EPV ~155亿，而市值 1182亿——**87% 的市值是"铀价超级周期 + 集团资产注入"的期权定价**；三支柱纪律下这不是 DDM 世界能解释的票，买它是买周期位置，不是买价值折让。

## 一、支柱① 再生产价值 Reproduction Value（原书称资产价值 AV）

> 口径同前：**重置成本**（replacement）= 购置同性能旧资产的价格；**再生产成本**（reproduction）= 竞争者今天从零复制同等经营能力的新建成本——原书取后者。调整方法依据 Hudson General 案例科目调整表。

| 科目（2026H1 账面，亿元） | 账面 | 调整逻辑 | 再生产价值 |
|---|---|---|---|
| 货币资金 | 73.5 | 面值 | 73.5 |
| 其他流动资产 | 15.6 | 拆不出构成，×0.9 | 14.0 |
| 应收 + 票据 | 59.9 | +坏账准备 ~1.0（客户为中核体系/电厂，体制内坏账风险低） | 60.9 |
| **存货（铀产品）** | 105.4 | **重置价口径**：账面按历史采购成本，现货 $90/lb、长协 $96.5 创历史新高 → 重置 ×1.15~1.3 | **130 (120~145)** |
| 预付 | 3.5 | 面值 | 3.5 |
| 固定 + 在建 | 46.0 | 矿山设备重置 ×1.15 | 53 (48~58) |
| **无形资产** | **3.8** | ⚠️ **仅按账面计**——矿业权几乎未表内化（见下方陷阱） | 3.8 |
| 递延税资产 | 4.3 | 折现 ×0.8 | 3.4 |
| 使用权/长股/其他金融/其他 | 22.9 | 面值 | 22.9 |
| **重置总资产** | | | **~365** |
| − 全部负债 | 155.1 | 面值（短借 41.3 + 一年内 1.4 + 长借 31.4 + 租赁 3.4 ≈ 77.5 有息，其余经营） | −155.1 |
| **有形再生产价值（权益）** | | | **≈ 210 亿 (185~240)** |

```
再生产价值（全书口径）= 有形 210 亿（每股 ~10.2 元）
  + 特许权重置：⚠️ 不计量、只定性——铀矿勘探开采属国家战略管制专营，
    私营资本无法"重建"，三费资本化法失效（8.7 亿三费是体制运行成本，
    不是品牌/渠道重建成本；对 toB 专营企业套 1×三费没有意义）
AV/市值 = 18%——地板在 18 层，现价在 100 层

复刻预算：N/A（牌照型垄断，复刻成本对私人资本 = ∞）
  类比：汾酒的"不可复刻"再进一级——汾酒还能掏钱买品牌故事，
  铀矿牌照连买都不存在市场
```

**⚠️ 资源股的特殊陷阱（本票 AV 系统性失真，必须明说）**：
1. **矿业权几乎未表内化**：无形资产仅 3.8 亿，而公司真实经济资源（铀矿储量、探矿权、开采资质）账面接近零。若按储量×铀价重估，资源价值远高于表内 AV——但资源量、品位、开采成本数据需招股书/年报附注支持，本笔记不拍脑袋。
2. **存货重置是 AV 的最大水分也是最大弹性**：105 亿存货按现价重置上浮 25 亿，但一旦铀价回落，重置溢价同步蒸发——资源股的 AV 本身随商品价波动，不如消费品 AV 稳定。
3. Greenwald 调整表（为 Hudson General 这类制造/服务企业设计）**没有"矿业权重置"行**——资源类公司需自设科目，本表是第一次尝试，误差可能很大。

## 二、支柱② EPV：经营权价值

```
正常化盈利：16~18 亿，取 17 亿
  依据：2025 扣非 16.2 亿为锚；2026E ~20 亿（H1 9.7 年化）不线性外推——
  铀价长协 $96.5 已是历史新高区域（超 2007 峰值），周期股取中周期盈利
  而非现货盈利：若铀价回落至 $70，盈利回到 13~14 亿
现金盈利 = 17 + D&A 4.6 − 维护性 capex ~5 ≈ 16.6 亿 ≈ 净利 ✓
  （D&A≈维护 capex，稳态成立；但注意 2025 总 capex 19.3 亿 >> 现金盈利，
  扩张期 FCF 为负，EPV 隐含"扩张投入由持续融资支撑"的假设）

r_e = 11%（有息负债 77.5 ≈ 货币 73.5，净债≈0，不折 WACC）
  取 11% 而非 9.5%：商品价格周期 + 体系内定价管制 + 次新股波动溢价

EPV = 17 / 0.11 ≈ 155 亿（每股 ~7.5 元）
  敏感：r=12% → 142 亿；r=10% → 170 亿；铀价 $70 场景 → EPV ~120 亿
EPV/市值 = 13%
```

**AV vs EPV 对照 —— 情形 A（AV > EPV）**：

| | 中国铀业 | 山西汾酒 | 伊利股份 |
|---|---|---|---|
| 有形再生产价值 | ~210 亿 | ~443 亿 | ~735 亿 |
| EPV | ~155 亿 | ~1110 亿 | ~1050 亿 |
| **AV − EPV** | **+55 亿** | −667 亿 | −315 亿 |

Greenwald 读法：AV > EPV = 按重置成本买下这些资产，其当前盈利撑不起资产价值——要么市场未充分定价（机会），要么资产盈利效率低（价值陷阱）。**商品上行周期早中段是第三种解释**：存货/产能重置价先涨（铀价 $90+），盈利因长协滞后 + 贸易混合毛利薄而没跟上。这与汾酒（AV<EPV，收租型）和伊利（AV≈EPV，成本壁垒型）是三种完全不同的生意。

## 三、支柱③ 增长价值：市场相信的

```
反推隐含永续增长 g*：
  17 × (1+g) / (0.11 − g) = 1182亿 → g* ≈ 9.5% 永续
对照：伊利 g*≈3.7%（合理带内），汾酒 g*≈8%（偏高但逻辑自洽）
  中国铀业 g*≈9.5% 永续——任何永续增长模型都无法合理化
现价结构拆解：EPV 155 亿（13%）+ 增长/期权 1027 亿（87%）
```

**87% 的市值由三个期权构成**：
1. **铀价中枢上移期权**：长协 $96.5 创历史新高、Citi 看 $140（2027）；全球一次供应缺口 2028-2032 扩大、美国数据中心电力交易（Google 22 年购电协议）重启核电叙事。若长协中枢到 $110-120，自产矿放量 + 存货重估，盈利可到 25~35 亿。
2. **集团资产注入期权**：中核集团体外铀资源/海外权益的证券化预期——A 股"中字头 + 战略资源重组"主题的旗舰标的。注意：注入对老股东**不是免费午餐**（定增摊薄），市场按"注入想象"先行定价。
3. **核电需求扩张期权**：中国在建核电机组全球第一，2035 装机翻倍路径下天然铀需求 CAGR 6-8%，公司是国内唯一承担自主铀资源职能的上市主体——需求确定性是三个期权里最强的。

**fade（反方）**：长协价已超 2007 峰值（周期顶部叙事）；UBS 已警示宏观逆风、德州暂停数据中心并网可能拖延反应堆需求；哈萨克等供给恢复；次新股流通盘 8.4%，价格被资金面而非基本面主导。**若期权证伪，回 EPV 155 亿 = −87%。**

## 四、交叉验证

- **壹评级**：无覆盖（kimi_results 无快照）——本票无 DDM 外部锚。
- **可比公司**：中广核矿业（1164.HK）：市值 153.5 亿港元（≈141 亿人民币，中国铀业的 1/8.4），PB 3.4，**PE 不可用（亏损）**——港股铀标的同样不便宜且盈利更差；中国铀业 A 股稀缺性溢价明显。
- **市场定价口径**：PE(TTM) 59.8 / PB 6.8，A 股次新股 + "铀"唯一标的 + 央企重组主题三重溢价叠加；流通盘仅 8.4%（99 亿）决定短期价格与基本面弱相关。
- **结论**：无外部估值锚可校正，三支柱结论须保持方法学诚实——AV/EPV 仅作"地板与中枢"参照，不可当目标价。

## 五、结论速览

```
再生产价值  210亿   ← 含存货重置上浮 25亿；矿业权未表内化使此数系统性偏低
EPV        155亿   ← r_e 11%，中周期盈利 17 亿；每股 ~7.5 元
三支柱公允  155-300亿 ← 即便给 5% 永续增长也只有 ~300 亿（每股 ~14.4）
Graham买点  ≤103亿（每股 ~5.0元）← 距现价 −91%，纪律上完全不满足
现价       1182亿   ← g*≈9.5% 永续不可合理化；87% 为期权定价
```

| 维度 | 判定 |
|---|---|
| 资产/盈利支撑 | **18% / 13%**——地板与中枢都在 20 层以下 |
| 买入性质 | 周期 + 事件驱动（期权组合），非价值折让 |
| 纪律判定 | 三支柱框架下**不满足买入条件**；这是"看懂但不属于格雷厄姆买点"的票 |
| 若坚持参与 | 只能按周期股纪律：赌的是①铀价现货破 $100/长协 $110+，②注入公告落地——两者都是事件，不是估值 |

**风险清单**：① 铀价见顶回落（长协已超 2007 峰值）② 注入预期落空或定增摊薄超预期 ③ 次新股流通 8.4%，解禁/流动性冲击 ④ 贸易业务毛利薄，盈利弹性低于纯矿山股 ⑤ 体系内定价管制压制利润率上限 ⑥ FCF 持续为负依赖融资。
**看多催化**：① 现货破 $100 ② 长协价站稳 $100+ ③ 集团资产注入公告 ④ 新核电核准提速 ⑤ 国家天然铀战略储备采购放量。

**一句话**：中国铀业是"铀价超级周期 + 央企注入"的纯正期权标的——资产地板 210 亿、盈利中枢 155 亿都在现价 18 层以下，**这是周期定位的赌桌，不是价值投资者的餐桌**；想清楚自己在买期权，再决定仓位。

## 六、方法论复盘：资源/牌照型公司套三支柱的四个修正

1. **AV 的"矿业权黑洞"**：账面无形仅 3.8 亿、真实资源未表内化——Greenwald 调整表（为企业制造/服务设计）缺"资源储量重置"科目，资源股 AV 必须自设补行并标注不确定性。汾酒是"现金粉饰型"表观低估的镜像问题：铀业是"资源缺席型"表观高估（AV 显得低、其实资源在体外）。
2. **三费资本化法对专营 toB 企业失效**：8.7 亿三费不是"重建品牌/渠道"的成本，特许权只能定性（牌照不可复刻），不设倍数——否则会把体制运行费误当护城河重建费。
3. **EPV 必须用中周期盈利**：现货铀价历史新高的年份线性外推会虚增 EPV 30%+；取 2025 实际盈利而非 2026E 年化。
4. **g* 反推是周期股最好的照妖镜**：g*≈9.5% 永续一眼可见不可持续 → 立刻切换到"期权定价"心智模型，停止在 DDM 框架里找合理化解释。三支柱法的最大价值在这种时刻：它诚实地告诉你"这票不在本框架射程内"。
