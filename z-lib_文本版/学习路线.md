# 主线① 估值：把「值多少钱」变成可计算的东西

## 第 1 步 · 估值入门（先读薄的）

### 📘 The Little Book of Valuation — 达摩达兰
`The Little Book of Valuation How to Value a Company, Pick a Stock, and.txt`（30万字）

**为什么先读**：达摩达兰的《估值圣经》1356页太重，这本是他的简化版，一个周末能读完。

**抓这几章**：
- 内在价值 vs 相对价值：两套估值逻辑何时用哪套
- DCF 五件套：现金流 → 增长率 → 贴现率 → 终值 → 现值
- 终值（Terminal value）怎么算——**这是 DCF 里 60%+ 价值来源，也是最容易做手脚的地方**
- 相对估值：PE/PB/PS/EV-EBITDA 各自适用场景与陷阱

**读完你能**：拿到一份财报，能在 30 分钟内搭出一个三档估值（悲观/中性/乐观）

## 第 2 步 · 建立体系（最重要的一本）

### 📗 Value Investing: From Graham to Buffett and Beyond — 格林沃尔德
`Value investing  from Graham to Buffett and beyond ( etc.).pdf.txt`（109万字）

**为什么这本是核心**：它把「价值投资」从口号变成了三套可操作的估值方法。哥大商学院教材，逻辑极清晰。

**核心框架（三支柱估值法）**：

```
1. 资产价值 (Asset Value)
   └ 重置成本法：重建这家公司要花多少钱？
   └ 适用：重资产、周期底部、清算场景

2. 盈利能力价值 (EPV, Earnings Power Value)
   └ 公式：EPV = 可持续调整后盈利 / 资本成本
   └ 关键：用正常化盈利（剔除周期高点/一次性损益），不加增长！
   └ 适用：成熟稳定企业（如公用事业、消费龙头）

3. 增长价值 (Growth Value)
   └ 只有当"特许经营权"(franchise)存在时，增长才创造价值
   └ 公式：增长价值 = EPV × (ROE - 资本成本) 相关的溢价
   └ 陷阱：没有护城河的增长 = 毁灭价值
```

**关键洞察（书里反复强调）**：
- **EPV > 资产价值 才是特许经营权**：说明公司能在资产重置成本之上赚钱，有护城河
- **EPV ≈ 资产价值**：纯竞争行业，赚不到超额收益，增长无用
- **管理层资本配置在特许企业里影响巨大**——好公司被烂管理层毁掉的案例

**读完你能**：用三支柱法判断一家公司「贵在资产、贵在盈利、还是贵在增长」，这比单看 PE 深刻得多

## 第 3 步 · 选股与成长股（两种风格）

### 📙 One Up On Wall Street — 彼得·林奇
`One Up On Wall Street How To Use What You Already Know To Make Money I.txt`（59万字）

**核心方法：六类公司分类法**（书里原话 "six general categories"）
```
1. 缓慢增长型 (Slow Growers)    — 成熟、高分红，如公用事业
2. 稳健增长型 (Stalwarts)       — 大公司、10-12%增速，如可口可乐
3. 快速增长型 (Fast Growers)    — 20-25%增速，十倍股来源，风险也最大
4. 周期型 (Cyclicals)           — 汽车/钢铁/化工，时机最重要
5. 资产富余型 (Asset Plays)     — 账面资产被低估，如地产、现金
6. 困境反转型 (Turnarounds)     — 濒临破产但可能起死回生
```
**每类的买卖逻辑完全不同**——这是林奇最实用的一招。

**必读章节**：
- 「Stalking the Tenbagger」十倍股怎么找（从生活中发现）
- 「The Two-Minute Drill」两分钟独白：能不能两分钟讲清买入理由
- 「The Final Checklist」13 条检查清单（可当模板用）
- PEG 指标：PE / 增长率，林奇用它给成长股定价

**读完你能**：拿到一只票，先归类，再用对应类别的方法论判断

### 📕 非常潛力股（Common Stocks and Uncommon Profits）— 费雪（繁中）
`非常潛力股 = Common Stocks and Uncommon Profits and Other Writings (菲利普 · 費.txt`（17万字）

**与林奇的互补**：林奇偏定量+分类，费雪偏定性+调研。

**核心方法**：
- **「闲聊法」（Scuttlebutt）**：通过供应商、客户、前员工、竞争对手了解公司真相
- **15 要点**：从产品市场潜力、研发效率、利润率、管理层诚信等 15 个维度评估成长股
- **集中持股**：找到真正优秀的公司就该重仓，而不是分散到平庸公司

**读完你能**：知道如何做「财报之外」的定性调研

# 主线③ 风险与决策：先保证不亏大钱

## 📙 The Dao of Capital — 斯皮茨纳格尔
`The Dao of Capital (Mark Spitznagel).pdf.txt`（75万字）

**核心思想**：奥地利学派投资哲学——**「以迂为直」**
- 迂回生产：先建工具再打猎，短期慢但长期快
- 时间偏好：延迟满足是投资的核心优势
- 与塔勒布《黑天鹅》同源，强调**凸性（convexity）**

**这本书偏哲学**，好处是改变你对「等待」和「布局」的认知。慢读。

## 📘 Safe Haven — 斯皮茨纳格尔
`Safe Haven (Mark Spitznagel).pdf.txt`（39万字）

**核心**：避险资产不只有黄金/债券，书里提出**「避险光谱」（safe haven spectrum）**
- 按「成本 vs 收益」给各种避险工具排序
- 关键问题：**你持有对冲的成本是多少？在什么情况下它会生效？**
- 结论常反直觉：很多"避险资产"其实是伪避险

**读完你能**：判断你的组合真正需要什么对冲，而不是跟风买黄金

## 📗 Principles — 瑞·达利欧
`Principles Life and Work (Ray Dalio).epub.txt`（93万字）

**可操作部分**（跳过自传和团队管理章节）：
- **拥抱现实，deal with it**：痛苦 + 反思 = 进步
- **极度求真、极度透明**：决策要基于事实而非面子
- **可信度加权决策**：不是民主投票，也不是独裁，而是按专业度加权
- 决策流程：目标 → 问题 → 诊断 → 方案 → 执行

**读完你能**：建立一套自己的决策检查机制，减少情绪化操作

# 主线② 周期：判断「现在在哪」

## 📘 Mastering the Market Cycle — 霍华德·马克斯
`Mastering the Market Cycle Getting the Odds on Your Side (Howard Marks.txt`（51万字）
📕 繁中版：`掌握市場週期：價值投資大師霍華 · 馬克斯教你看對市場時機，提高投資勝算...txt`（18万字）

**核心命题**：**「我们无法预测，但可以准备」**（Can't predict, can prepare）

**书的结构（按周期层次递进）**：
```
第1层  经济周期 (The Cycle in the Economy)
第2层  利润周期 (The Cycle in Profits)
第3层  心理钟摆 (The Pendulum of Investor Psychology)  ← 核心
第4层  风险态度周期 (The Cycle in Attitudes toward Risk)
第5层  信贷周期 (The Credit Cycle)                     ← 最危险的一个
第6层  不良债务周期 / 房地产周期
汇总    市场周期 (The Market Cycle)
应用    周期定位 (Cycle Positioning) + 应对局限 (Limits on Coping)
```

**必须记住的两句话**：
1. **「钟摆」理论**：投资者心理在「贪婪↔恐惧」间摆动，从不停在理性中点
2. **周期定位五步**：识别位置 → 理解风险偏好 → 逆向准备 → 控制风险 → 等待钟摆回摆

**读完你能**：用一张表评估当前市场温度（估值/情绪/信贷/风险偏好），调整仓位

## 📙 Any Happy Returns — 彼得·奥本海默
`Any Happy Returns Structural Changes and Super Cycles in Markets (Pete.txt`（61万字）

**核心**：**超级周期（Super Cycles）**——比普通周期更长（10-20年）的结构性变化
- 长期资产回报的驱动因素
- 股债轮动、利率长期趋势
- 价值/成长风格的长期切换

**与马克斯的区别**：马克斯讲「现在该防守还是进攻」，奥本海默讲「未来10年的大格局」

## 📕 高盛首席分析師教你看懂進場的訊號（The Long Good Buy）— 奥本海默（繁中）
`高盛首席分析師教你看懂進場的訊號：洞悉市場週期，贏在長期好買賣 = The Long Good Buy Analysing Cycles i.txt`（15万字）

**同作者的实操版**，比上本更聚焦**择时框架**：
- 牛熊周期各阶段特征
- 用估值 + 宏观指标判断周期位置
- 「长期好买点」（The Long Good Buy）出现在什么条件下

## 📚 Big Debt Crises — 瑞·达利欧
`Big Debt Crises (Ray Dalio Mark Kirby).epub.txt`（117万字）

**结构**（按理解顺序读）：
```
PART 1: 典型大债务周期模板 (The Archetypal Big Debt Cycle)
        └ 信贷/债务如何运作 → 周期阶段 → 去杠杆的三种方式
PART 2: 三个详细案例（2008美国 / 1930s大萧条 / 1920s魏玛德国）
PART 3: 48 个历史案例的压缩版（当资料库查）
```

**核心工具——去杠杆三支箭**：
```
1. 财政紧缩 (Austerity)      — 削减开支
2. 债务违约/重组 (Default)   — 赖账
3. 印钞/债务货币化 (Printing) — 通胀消化
合理组合 = "漂亮的去杠杆" (Beautiful Deleveraging)
失衡     = 通缩性萧条 或 恶性通胀
```
**判定标准**：名义增长率 > 名义利率，去杠杆才可持续

**读完你能**：识别一个经济体处在债务周期的哪个阶段，预判政策走向

## 📗 The Changing World Order — 瑞·达利欧
`The Changing World Order Why Nations Succeed and Fail (Ray Dalio).epub.txt`（81万字）

**核心框架**：
```
一国的兴衰 = 三大力量 (Three Forces)
├ 1. 长期债务与资本市场周期
├ 2. 内部秩序与混乱周期（贫富分化、政治极化）
└ 3. 外部秩序与混乱周期（大国竞争、储备货币地位）

帝国生命周期：新秩序 → 和平繁荣 → 过度扩张 → 泡沫破裂 → 内战/革命 → 新秩序
```
**关键洞察**：**储备货币国享有特权，但也会因过度负债而失去它**（荷兰→英国→美国的更替）

**与你投资的关系**：判断长期汇率、资产配置的大背景
