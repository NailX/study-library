`` AV ≈ 归母净资产 537 亿（清算口径需再打折扣，取 500-560 亿区间） AV/市值 = 30% → 表面与汾酒（28%）同档，但结构完全相反 ``

与汾酒的关键差异：汾酒是"零有息负债+存货增值"的 30%，伊利是"重资产+净负债约 487 亿"的 30%。同样的 AV 占比，风险结构相反——伊利的 647 亿短借多为低息流动性贷款（票据池/信用证），日常利息负担不重，但货币资金仅 166 亿，覆盖不足 1/4，遇到信用环境收紧时是真实的脆弱点。

含义：AV 只是极端场景地板，对伊利这类渠道品牌企业同样没有定价意义——但净负债结构意味着 AV 之下没有"现金垫子"，下行段的底部支撑弱于汾酒。

二、支柱② EPV ≈ 1050 亿（核心）

正常化盈利（本案例最关键的判断）

``` 不能用什么： ✗ 2024年84.5亿（扣非仅60.1亿）—— 减值+原奶周期双底，过度悲观 ✗ 2025年115.7亿（扣非110.7亿）—— 修复顶+低基数反弹，不可外推 ✗ 2026H1的-20%直接年化 —— Q2含大额减值且为单季极端值

Greenwald式处理：穿越周期的可持续盈利 ├ 悲观（2026-27磨底延续，扣非回落至75亿级）: 85 亿 ├ 中性（H2低基数企稳，全年扣非~95亿）: 100 亿 ← 基准 └ 乐观（奶价回升+减值出清，修复至2025的90%）: 110 亿

依据：2023-25三年扣非均值 90.4 亿； 2016-2025十年扣非 CAGR +10.5%，中枢约100亿； 毛利率常年 32-37%、2026H1仍36.4% → 盈利质量未崩，是"量"的问题不是"质"的问题； OCF常年 130-220 亿 >> 净利 → 利润含现金量极高 ```

EPV 计算

``` EPV = 正常化盈利 / 股权成本率

股权成本率取 9.5%：β≈0.65的消费白马表面可更低， 但①净负债487亿 ②行业处下行段 ③人口长逻辑逆风—— 股权成本不应按顺境下调（DCF常见错误，且必须用r_e而非WACC， 因为归母盈利已扣利息，避免杠杆被双重计算）

EPV = 100 / 9.5% ≈ 1050 亿（每股 16.6 元） 无有息负债净现金可加 —— 相反，净负债风险已通过9.5%的r_e反映 ```

三、支柱③ 增长价值 = 全部分歧所在

情形判定：确认情形 C（特许权企业）

`` ROE 20.9% (2025) >> 股权成本 9.5% 特许权来源： ├ 渠道：百万级终端网点，县乡下沉能力全行业第一 ★最持久 ├ 品牌矩阵：伊利/安慕希/金典/金领冠多价位带覆盖 └ 规模经济：原奶采购+自有牧场+冷链物流全产业链，成本曲线最低 → 增长有价值，EPV 不是终点 ``

但增长价值必须扣 fade

``` 出生人口 2016 年 1786 万见顶 → 2023 年 902 万腰斩 → 乳制品总量天花板已封死 长期增长中枢 ≠ 历史 10%+，对冲项只有： 低温鲜奶渗透 / 奶酪 / 成人营养品 / 出海 / 行业集中度提升（双寡头收割小厂） fade 调整：行业总量下移 → 永续 g 上限取 2.5~3%

公允价值 = 100 × (1+g) / (9.5% − g)

g=0% → 1050亿（16.6元/股） g=2% → 1360亿（21.5元/股） g=3% → 1585亿（25.1元/股） g=4% → 1890亿（29.9元/股） g=5% → 2330亿（36.8元/股）

★ 现价1784亿 隐含永续增长 g* ≈ 3.7% ```

市场隐含结构拆解

`` 现价 1784亿 = EPV 1050亿 + 增长价值 734亿（占比41%） → 比汾酒的21%高得多：市场给伊利的"增长+类债白马"双重溢价 → 4.9%股息率说明市场并未对增长绝望，定价是"温和乐观" ``

反推壹评级 DDM 的隐含假设：

``` 按 2025 年度分红约 87 亿（每股1.38元 × 63.25亿股）： 2642 = 87×(1+g)/(r−g) ├ 若 r=8% → g ≈ 4.9% ← ★永续增速偏高 └ 若 r=9% → g ≈ 6.2% ← ★明显过高 或者显性期10年年化7-8%增长 + 永续3%的多段DDM

张力存在但弱于汾酒：壹评级给伊利 growth 仅 3 星，与隐含 g≈5% 矛盾； 但汾酒是"2星 vs 6.5%"的硬矛盾，伊利是"3星 vs 5%"的软矛盾。 ```

另一个时间维度的检验：壹评级报告发布于 2025-09-11，当时股价 28.21 元；13 个月后的今天 28.20 元——"低估 +48%"的判断至今未被市场兑现，且 2026H1 扣非 -20% 已部分证伪其"液态乳平稳增长"的前提。保守解读：要么市场错了，要么 DDM 的显性期假设偏乐观。

分歧根源不在算力，在长期增长信念：

场景公允价值结论

我的判断（基于三支柱纪律）：

  • 壹评级 2642 亿需要"未来十年年化 7%+ 增长"支撑，在出生人口腰斩的现实面前，这是对 fade 纪律的绕开
  • 三支柱中性结论：公允区间 1360-1600 亿，现价 1784 亿 = 合理偏贵 10-15%，margin of safety 为负
  • 但与汾酒不同：伊利多一层 4.9% 股息垫 + 75% 分红率，持有体验与纯估值结论要分开评价

六、本案例的方法论复盘

  1. 正常化盈利是三支柱的灵魂：伊利 2024 扣非 60.1 亿 vs 2025 扣非 110.7 亿，一年之间差 84%——乳业周期叠加商誉减值，使报表利润剧烈波动。用任何单一年份做基数都会得出荒谬结论；十年扣非 CAGR +10.5% 的中枢（100 亿）才可靠。
  2. 同样的 AV 占比，相反的风险结构：汾酒 28% 与伊利 30% 的数字巧合背后，是"零负债+存货增值"与"重资产+净负债 487 亿"的两极。AV 只是入口，结构分析才能告诉你地板有多硬。且伊利有杠杆，EPV 必须用股权成本率 r_e 而非 WACC，否则利息被双重计算。
  3. 高股息是双刃：4.9% 股息率既是下行保护，也是市场"增长绝望"程度的报价单。伊利 41% 的增长溢价说明市场并未绝望，但 g* 3.7% 与人口 fade 上限 3% 之间的差，就是要不要用真金白银回答的问题。
  4. EPV 是最大的 sanity check：无论 DDM 多花哨，"零增长也值 1050 亿（16.6 元）"是锚。现价高于锚 70%——你多付的 734 亿买的是"周期修复+集中度提升+第二曲线"三张期权，每张都要单独验证。
