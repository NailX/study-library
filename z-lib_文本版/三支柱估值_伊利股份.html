★ 关键修正：伊利不是"净负债公司"，是"存贷双高"

``` 初版只看 货币166亿 vs 短借647亿 → 误判"净负债487亿"

但伊利报表里还散落着 ~660-850亿 金融资产： 其他流动资产 240亿（理财/结构性存款） 其他非流动资产 419亿（长期存款/财务公司贷款等，构成不透明） 一年内到期非流动资产 47亿

金融资产合计 ≈ 660-850亿 vs 金融负债 ≈ 712亿（短借647+应付票据58+长借等） → 真实净金融敞口 ≈ -50亿（保守）~ +130亿（面值），中枢 ≈ 0

即"存款端与借款端大体相抵"的产业链金融结构（票据池/财务公司利差）。 风险不是"还不上钱"，而是资金效率、财务公司资产质量、419亿科目构成不透明。 ```

特许权重置成本（三费资本化）

``` Greenwald 原书口径：竞争者重建品牌+渠道，需一次性投入近一年的三费 2025年三费 = 销售215.4 + 管理47.0 = 262.4亿 → 特许权重置成本 ≈ 262亿

国内部分实践取 3-5×三费 = 787~1312亿 —— 本分析不取： 三费是每年持续发生的维持费用，不是一次性投入； 3-5x 实质是把 EPV 里的特许权价值重复塞进 AV，会得出 AV≈EPV 的循环结论。

AV（全书口径）= 有形AV 480 + 特许权重置 262 ≈ 740亿（每股 ~11.7元） 区间 640-850亿（视419亿科目金融属性比例） AV/市值 = 36-48%

教科书对照：EPV 1050亿 − AV（含特许权重置）740亿 ≈ 310亿 = 特许权创造的超额价值（EPV > AV → 特许权真实创造价值，超额部分即护城河租金） ```

含义：地板仍然遥远（AV 仅市值 4 成），但地板"硬度"比初版判断的高——净金融敞口≈0，且 419 亿其他非流动资产提供隐藏厚度。待查证：其他非流动资产的年报构成（若为长期存款/财务公司贷款则按面值成立；若大量是预付设备款则需下调）。

二、支柱② EPV ≈ 1050 亿（核心）

正常化盈利（本案例最关键的判断）

``` 不能用什么： ✗ 2024年84.5亿（扣非仅60.1亿）—— 减值+原奶周期双底，过度悲观 ✗ 2025年115.7亿（扣非110.7亿）—— 修复顶+低基数反弹，不可外推 ✗ 2026H1的-20%直接年化 —— Q2含大额减值且为单季极端值

Greenwald式处理：穿越周期的可持续盈利 ├ 悲观（2026-27磨底延续，扣非回落至75亿级）: 85 亿 ├ 中性（H2低基数企稳，全年扣非~95亿）: 100 亿 ← 基准 └ 乐观（奶价回升+减值出清，修复至2025的90%）: 110 亿

依据：2023-25三年扣非均值 90.4 亿； 2016-2025十年扣非 CAGR +10.5%，中枢约100亿； 毛利率常年 32-37%、2026H1仍36.4% → 盈利质量未崩，是"量"的问题不是"质"的问题； OCF常年 130-220 亿 >> 净利 → 利润含现金量极高 ```

EPV 计算

``` EPV = 正常化盈利 / 股权成本率

股权成本率取 9.5%：β≈0.65的消费白马表面可更低， 但①净负债487亿 ②行业处下行段 ③人口长逻辑逆风—— 股权成本不应按顺境下调（DCF常见错误，且必须用r_e而非WACC， 因为归母盈利已扣利息，避免杠杆被双重计算）

EPV = 100 / 9.5% ≈ 1050 亿（每股 16.6 元） 金融敞口≈0（见支柱①修正），杠杆风险溢价已含在 9.5% 的 r_e 中，不再重复调整 ```

现金盈利校验（维护性资本开支）

``` Greenwald 要求 EPV 用"现金盈利"而非报表盈利： 现金盈利 = 正常化净利 + 折旧摊销 − 维护性资本开支

伊利 D&A（2025）: ≈46亿（固定+生物资产折旧40.7 + 无形3.6 + 使用权等1.7） 维护性 capex: ≈40-45亿（成熟乳企，与折旧同量级） 2024-25 实际 capex: 39.8 / 30.4亿 —— 低于维护线（收缩期，吃存量资产）

现金盈利 ≈ 100 + 46 − 43 ≈ 103亿 ≈ 报表正常化盈利 → EPV 无需因 capex 下调（1050 亿稳态成立）

边界情形：2019-2023 年 capex 65-92亿 >> D&A 38-83亿， 那是扩张期增长投资，不应从盈利中扣——但若在彼时的扩张顶点做 EPV， 必须剔出增长成分，否则会把"烧钱扩张"误判为"现金创造"。 ```

三、支柱③ 增长价值 = 全部分歧所在

情形判定：确认情形 C（特许权企业）

`` ROE 20.9% (2025) >> 股权成本 9.5% 特许权来源： ├ 渠道：百万级终端网点，县乡下沉能力全行业第一 ★最持久 ├ 品牌矩阵：伊利/安慕希/金典/金领冠多价位带覆盖 └ 规模经济：原奶采购+自有牧场+冷链物流全产业链，成本曲线最低 → 增长有价值，EPV 不是终点 ``

但增长价值必须扣 fade

``` 出生人口 2016 年 1786 万见顶 → 2023 年 902 万腰斩 → 乳制品总量天花板已封死 长期增长中枢 ≠ 历史 10%+，对冲项只有： 低温鲜奶渗透 / 奶酪 / 成人营养品 / 出海 / 行业集中度提升（双寡头收割小厂） fade 调整：行业总量下移 → 永续 g 上限取 2.5~3%

公允价值 = 100 × (1+g) / (9.5% − g)

g=0% → 1050亿（16.6元/股） g=2% → 1360亿（21.5元/股） g=3% → 1585亿（25.1元/股） g=4% → 1890亿（29.9元/股） g=5% → 2330亿（36.8元/股）

★ 现价1784亿 隐含永续增长 g* ≈ 3.7% ```

市场隐含结构拆解

`` 现价 1784亿 = EPV 1050亿 + 增长价值 734亿（占比41%） → 比汾酒的21%高得多：市场给伊利的"增长+类债白马"双重溢价 → 4.9%股息率说明市场并未对增长绝望，定价是"温和乐观" ``

反推壹评级 DDM 的隐含假设：

``` 按 2025 年度分红约 87 亿（每股1.38元 × 63.25亿股）： 2642 = 87×(1+g)/(r−g) ├ 若 r=8% → g ≈ 4.9% ← ★永续增速偏高 └ 若 r=9% → g ≈ 6.2% ← ★明显过高 或者显性期10年年化7-8%增长 + 永续3%的多段DDM

张力存在但弱于汾酒：壹评级给伊利 growth 仅 3 星，与隐含 g≈5% 矛盾； 但汾酒是"2星 vs 6.5%"的硬矛盾，伊利是"3星 vs 5%"的软矛盾。 ```

另一个时间维度的检验：壹评级报告发布于 2025-09-11，当时股价 28.21 元；13 个月后的今天 28.20 元——"低估 +48%"的判断至今未被市场兑现，且 2026H1 扣非 -20% 已部分证伪其"液态乳平稳增长"的前提。保守解读：要么市场错了，要么 DDM 的显性期假设偏乐观。

我的判断（基于三支柱纪律）：

  • 壹评级 2642 亿需要"未来十年年化 7%+ 增长"支撑，在出生人口腰斩的现实面前，这是对 fade 纪律的绕开
  • 三支柱中性结论：公允区间 1360-1600 亿，现价 1784 亿 = 合理偏贵 10-15%，margin of safety 为负
  • 但与汾酒不同：伊利多一层 4.9% 股息垫 + 75% 分红率，持有体验与纯估值结论要分开评价

六、本案例的方法论复盘

  1. 正常化盈利是三支柱的灵魂：伊利 2024 扣非 60.1 亿 vs 2025 扣非 110.7 亿，一年之间差 84%——乳业周期叠加商誉减值，使报表利润剧烈波动。用任何单一年份做基数都会得出荒谬结论；十年扣非 CAGR +10.5% 的中枢（100 亿）才可靠。
  2. 同样的 AV 占比，风险结构大改：初版按"货币 vs 短借"判断伊利为净负债 487 亿公司；按书中口径拆出 660-850 亿散落的金融资产后，真实净金融敞口≈0——伊利与汾酒的分野不是"负债 vs 无负债"，而是"存贷双高金融结构 vs 真零负债"。EPV 仍需用 r_e 而非 WACC（利息已在净利中扣除），但 9.5% 里的杠杆溢价偏保守。
  3. 高股息是双刃：4.9% 股息率既是下行保护，也是市场"增长绝望"程度的报价单。伊利 41% 的增长溢价说明市场并未绝望，但 g* 3.7% 与人口 fade 上限 3% 之间的差，就是要不要用真金白银回答的问题。
  4. EPV 是最大的 sanity check：无论 DDM 多花哨，"零增长也值 1050 亿（16.6 元）"是锚。现价高于锚 70%——你多付的 734 亿买的是"周期修复+集中度提升+第二曲线"三张期权，每张都要单独验证。
  5. 本次修订的教训（代理算法的代价）：初版用"归母净资产代理 AV + 只看货币资金 vs 短借"两个偷懒，得出"净负债 487 亿、AV 下无现金垫"的错误结论。按书中口径逐项重算后：伊利金融资产散落于其他流动/非流动科目合计 660-850 亿，净金融敞口≈0；AV（含三费资本化的特许权重置 262 亿）740 亿。Greenwald AV 方法的价值恰恰在逼你把资产负债表逐项拆开——代理算法会漏掉 419 亿的"其他非流动资产"。另：三费资本化取 ~1x（原书口径），3-5x 是把 EPV 的特许权价值重复塞进 AV。
