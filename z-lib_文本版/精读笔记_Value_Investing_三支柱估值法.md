## 一、这本书解决什么问题

主流估值（DCF）把**资产、盈利、增长**揉进一个 NPV 公式里，结果是：终值假设一变，估值天差地别，"garbage in, gospel out"。

Greenwald 的核心主张：**把价值的三个来源拆开算、独立验证，从最可靠到最不可靠排序**——

```
可靠性从高到低：
资产价值  >  盈利能力价值 EPV  >  增长价值
（看得见）    （可正常化验证）      （最依赖假设）
```

> 原文："The distinctiveness of the Graham and Dodd approach to valuation is to address these three elements of value **separately**, not to integrate them into a single ratio or NPV calculation."

## 二、三支柱框架（全书的心脏）

### Figure 3.1 — 三要素

| 支柱 | 定义 | 何时用 |
|---|---|---|
| **① 资产价值** AV | 持续经营企业 = **净资产重置成本**；不可持续 = **清算价值** | 重资产、周期底部、困境反转 |
| **② 盈利能力价值** EPV | 可持续的**正常化盈利 ÷ 资本成本**（不加增长！） | 所有企业的基准估值 |
| **③ 增长价值** GV | 只有**特许经营权**下的增长才创造价值 | 有护城河的成长股 |

### Figure 3.2 — AV vs EPV 的三种情形（估值诊断图）

```
情形A: AV > EPV      → 资产比赚钱能力值钱
         └  either 资产高估（该用清算价值？）
         └  or 管理层经营不善（价值毁灭者）

情形B: AV ≈ EPV     → 完美竞争行业（±12%以内）
         └ ROE ≈ 资本成本，无护城河
         └ 增长不创造价值 → 别为增长付溢价

情形C: EPV > AV     → ★ 存在特许经营权（franchise）
         └ 赚的超出了资产重置成本 = 有进入壁垒
         └ 此时增长才有价值，才进入第三步估值
```

> Magna 案例实证：十年平均 ROE 10.4% ≈ 估计股权成本 10% → 判定为情形B，无特许权，**增长价值≈0**。这就是"别给平庸增长付钱"的量化判据。

## 三、支柱① 资产价值：从账面价值到重置成本

**原则**：账面价值是历史成本，不是价值。要一项项调整为"今天重建这些资产要花多少钱"。

### 科目调整表（原文 Table，Hudson General 案例）

| 科目 | 调整方法 |
|---|---|
| 应收账款 | 加回坏账准备；按实际回款能力调整 |
| 存货 | 加回 LIFO 准备；周转过慢的按清算价下调 |
| 递延税项 | 折现到现值 |
| PP&E | 原始成本 + 物价/质量调整（设备按"已用一半寿命"近似，误差约10%） |
| 商誉 | 与产品组合/研发挂钩部分保留 |
| 研发支出 | ★ 资本化（会计上费用化了，但它是资产） |

**设备价格调整示例**：设备寿命 8 年 → 平均年龄 4 年；设备价格年跌 4% → 重置成本 = 原值 × (1-4%)⁴。美国商务部跟踪设备价格指数。

**用途**：
- 为情形A（AV>EPV）的资产型公司定价（净 nets、地产、控股公司）
- 为困境反转设定"地板价"

## 四、支柱② EPV：盈利能力价值

### 核心公式

```
EPV = 正常化可持续盈利 ÷ 资本成本 WACC

其中正常化盈利要做四项调整：
1. 平滑周期性（用穿越周期的平均盈利，别用景气顶/底）
2. 统一税率（用正常税率，剔除一次性税项——Magna 案例：
   2008年报表PE 31.5倍，正常化后只有 3.5倍！）
3. 研发费用还原（把当期费用化的研发加回利润，再摊销）
4. 经营租赁负债化（租金→利息+折旧）
```

### EPV 之上，还要加减"非经营性项目"

```
EPV(整体) = EPV(核心业务) + 多余资产 − 隐蔽负债

多余资产：富余现金、证券组合、参股公司、闲置地产
隐蔽负债：养老金缺口、环境负债、重组负债
```

> 原文："To the extent that these extraneous assets can be disposed of without affecting the ongoing functioning of the core businesses, they represent a source of value **in addition** to the value of sustainable earnings."

**两个铁律**：
1. EPV **不含任何增长假设**——它回答"这家公司静止不动值多少钱"
2. 预测新产品的分析师业绩记录极差（random + systematic error），所以增长留到最后单独处理

## 五、支柱③ 增长价值：只有特许权的增长才值钱

### 增长创造价值的条件（原文逻辑链）

```
增长需要投入现金 → 当期可分现金减少
所以增长的价值 = 增量回报 vs 资本成本的差额

投入1亿美元增长：
├ 回报 > 资本成本 → 创造价值 ✓
├ 回报 = 资本成本 → 白忙（情形B，竞争行业）
└ 回报 < 资本成本 → 毁灭价值 ✗（情形A，越多增长死得越快）
```

> 原文三种情形的结论：
> - **Case A**：增长是敌人——"growing companies of this kind are worse investments than static or shrinking ones"
> - **Case B**：增长无关紧要——竞争会抹平一切超额回报
> - **Case C**：只有被**进入壁垒保护**的增长（franchise growth）才创造价值

### 特许经营权 = EPV > AV 的差额

```
特许权价值 = EPV − AV   （即超出重置成本的赚钱能力）

护城河来源（Greenwald 版）：
├ 供给侧：专利/牌照/专有技术（最难持续）
├ 需求侧：客户锁定（转换成本/习惯/网络效应）★最持久
└ 规模经济：局部市场规模下固定成本摊薄（有限市场里的巨头）
```

### 特许权估值三参数（Ch8 + 附录）

```
1. 特许权下的增量 ROIC（区别于存量资产回报率）
2. 增长可以持续多久 = 特许权"半衰期"（half-life）
3. Fade rate（衰减率）= 72 ÷ 半衰期

例：半衰期 80 年 → fade ≈ 0.9%/年（可忽略）
    半衰期 18 年 → fade ≈ 4%/年（严重！科技特许权常见）
    ★ 半衰期 ≤ 25 年（fade ≥ 3%）必须认真扣减
```

> Intel/Apple 类科技特许权半衰期可能只有 15-20 年。给科技股做 DCF 却不扣 fade，是系统性高估。

### 回报拆解公式（Ch8 附录，特许权企业估值）

```
特许权企业的总回报 = 三部分之和：
1. 现金回报：每股增量盈利 × 分红率
2. 有机增长价值：留存收益的复利
3. 再投资回报：留存款项主动再投资产生的价值
```

|---|---|---|---|
| **Hudson General** | 资产富余型 | 资产价值法 | 拆出非经营资产，核心资产+多余资产分别定价 |

## 七、安全边际与买入纪律

> 格雷厄姆原文规则（本书重申）：
> **安全边际 ≈ 价值的 1/2，最低不低于 1/3**

```
master recipe（原文）：
1. 估算证券的基本价值
2. 与市场报价比较
3. 价格低于价值足够多 → 买入
4. 每家后裔（Buffett/Klarman/…）的差异只在：怎么估价值、要多少margin、买多少仓位
```

## 八、风险与组合构建（Ch10）

### 风险的正确度量

```
✗ 方差/波动率（Markowitz）—— 两大缺陷：
   1. 用价格而不是价值 → 价格下跌但价值没变 ≠ 风险
   2. 对称假设 → 实际收益分布右偏，方差被上行波动主导

✓ 格雷厄姆-多德定义：风险 = 「永久资本损失」
   的可能性与规模（permanent impairment of capital）
```

### 组合构建三原则

1. **分散度是相对的**：对你是个股集中风险，对满仓单一资产的家族可能只是必要分散——取决于持仓人整体资产负债表
2. **集中投资在理解+深度研究的标的上**（书中投资者画像：Buffett、Klarman、Schloss、Gabelli、Greenberg 各有风格，共同点是能力圈内下重注）
3. **风险管理的本质是买入价格**——足够大的 margin of safety 就是全部的风控

## 九、A 股实操检查清单（本书方法落地版）

```
【第一步 · 5分钟诊断】
□ EPV粗算：正常化净利 ÷ 10% ≈ 核心价值
□ EPV vs 市值：便宜多少？（margin ≥ 1/3 才看下去）
□ 多余资产/隐蔽负债：账上现金、理财、股权 vs 商誉暴雷、质押、担保

【第二步 · 定性判型】
□ 近5-10年 ROE 均值 vs 估计股权成本(8-10%)：
   ROE ≈ 成本 → 情形B，增长不值钱，就按EPV定价
   ROE 显著 > 成本 → 情形C，进入特许权分析
□ 护城河来源：转换成本？规模经济？牌照？
□ 特许权半衰期：消费品/医药 长；科技 短（fade≥3%要扣）

【第三步 · 交叉验证】
□ AV（重置成本）兜底：重资产公司地板价是多少？
□ 管理层资本配置记录：留存收益的 ROIC 历史
□ 一句话测试：能不能说清"市场错在哪"？说不清就不买
```
